Colophon

Static HTML and CSS. Published with GitHub Pages from Dylan-Texe/Dylan-Texe.github.io.

Type is Newsreader and IBM Plex Mono, both under the SIL Open Font License. No analytics.

The night scene is CSS and SVG: a sunset disc, perspective grid, scanlines, and grain. It sits behind the panels.

Living System links to its Vercel production domain, project-x-living-system-taupe.vercel.app. That project has no custom domain.

UFO '84 plays at ufo-80s.vercel.app. Pentaspace plays at pentaspace.vercel.app. Both addresses are UFO_PLAY_URL and PENTASPACE_URL in /js/play-urls.js.

Source only: Dylan-Texe/UFO-80s and Dylan-Texe/Pentaspace.

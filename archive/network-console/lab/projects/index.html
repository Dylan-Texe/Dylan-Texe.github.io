PROJECT_001

COMPLETE / DOCUMENTED

Windows Infrastructure Lab

A small-business style Windows environment built around Windows Server 2022. DC01 provides Active Directory and DNS for the corp.lab domain. CLIENT01 was installed, configured to use DC01 for DNS, joined to the domain, authenticated with a domain account and placed into the Workstations OU. A Workstation Baseline GPO was created and linked, and a successful policy refresh was performed. Live deployment was paused before the final DHCP/file-service expansion because the host reached its practical RAM and CPU limits. The repository retains the reconstruction procedures for DHCP, file services, permissions and deeper GPO verification.

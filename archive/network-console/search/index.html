Model Hardware Standard: agents get a driver layer for the physical lab

Anthropic's MHS research preview is not a robot and not a new model. It is a shared interface so agents can discover, describe, and operate programmable devices — with the hard problems still sitting in safety, spatial reasoning, and who writes the drivers.

Anthropic opens a research preview of the Model Hardware Standard

Anthropic published a primary announcement that MHS is in research preview with scientific labs and advanced manufacturers. The standard is model-agnostic, talks to existing programmable interfaces, and is intended to be open-sourced after safety work with partners.

Independent write-up: MHS as a common driver layer for physical agents

Kyle Orland's Ars Technica report restates the integration problem MHS claims to solve and notes that a common machine interface does not require an AI model — CLI and API control exist without one. MCP is the path that adds natural-language orchestration.

QuEra: agent-written laser lock recovers 99.3% of the time in MHS tests
